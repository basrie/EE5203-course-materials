1. Checkpoint B on paper (20 min)

Checkpoint B uses two functions. Read what each one does, then answer 1.1-1.4 on your own paper. Do this before you open your project.

The two functions of Checkpoint B

clamp_u16(value, low, high) keeps a value inside a range. If value is below low, it returns low. If value is above high, it returns high. Otherwise it returns value. In the lab the ADC range is 0 to 4095, so clamp_u16(4200, 0, 4095) returns 4095.

average_samples(values, count) adds the first count numbers of the array values. Then it returns the sum divided by count. Example: {2, 4, 6} and count 3 give (2 + 4 + 6) / 3 = 4.

Need a reminder? What each file holds (click)
  • A .h file (header) holds declarations: the name, the parameters and the return type of each function. It ends with ;.
  • A .c file with the same name holds the definitions: the code of each function, between { and }.
  • main.c holds the program that calls the functions.
  • CMakeLists.txt holds the list of .c files that the build compiles.

Checkpoint C: write led_init() and read the registers

Steps: Lab 3 guide, Checkpoint C (steps 1-4).

How to set and clear bits in C (click)

These examples use bit 7 and bits 7:6 of a register REG. Your code uses other registers and other bits. Change the register name and the bit numbers.

REG |= (1U << 7);      /* set bit 7. The other bits do not change. */
REG &= ~(3U << 6);     /* clear bits 7:6 (3 = binary 11, two bits) */
REG |= (1U << 6);      /* write the pattern 01 into bits 7:6 */
REG = (1U << 7);       /* write the whole register: only bit 7 is 1 */

Read the registers in the Registers Tree. In the lab this panel is called XPERIPHERALS. At home it is STM32CUBE REGISTERS TREE (Turkish VS Code: STM32CUBE KAYIT AĞACI). It is in the Run and Debug sidebar and appears when the debugger is running. Expand these three registers. Each field shows the bits you need.

Register Field Shows Used in
RCC → AHB1ENR GPIOAEN GPIOA clock: 0 = off, 1 = on C
GPIOA → MODER MODER5 PA5 mode: 0 = input, 1 = output (binary 01) C
GPIOA → ODR ODR5 PA5 level: 1 = LD2 on D

Read the field values. The hex number of the whole register also contains other bits, so it is not 0 or 1.

No Registers Tree? Use WATCH instead (click)

In Run and Debug, open WATCH, click + and add these three expressions. The program must be paused.

WATCH expression Same as
RCC->AHB1ENR & 1 GPIOAEN
(GPIOA->MODER >> 10) & 3 MODER5

If something goes wrong

  • The Registers Tree is empty or missing: it appears only while the debugger runs. Pause the program once. If it still does not appear, use WATCH (the box in Part 3).
  • WATCH shows an error instead of a number: the program must be paused. Check the spelling: GPIOA, MODER, ->.
  • undefined reference or implicit declaration: see your answers to 1.4.
  • LD2 never lights: MODER5 must be 1 after led_init.
  • The register hex number is not 0 or 1: normal. Read the field, for example MODER5.
  • Board not found: see If something goes wrong in the Home Setup Guide.

Still stuck? Send your lab assistant the step number and the first error line as text, not a photo. Do it before the weekend, so there is time to help.
