Two ways to set PA5

Both statements turn PA5 on. The hardware result is the same; the interface is different.

GPIOA->BSRR = (1U << 5);

HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);

Today we will connect every HAL name to the register behavior learned in L04.

HAL: another interface to GPIO registers

01 L04: calculate masks and write CMSIS registers directly.

02 TODAY: describe the same configuration with a HAL structure and functions.

03 EVIDENCE: inspect the registers after HAL runs and confirm the physical result.

HAL does not replace the hardware model. It gives the program another way to express it.

CMSIS = Common Microcontroller Software Interface Standard (Arm): standard C names for registers, such as GPIOA->MODER. HAL = Hardware Abstraction Layer (ST): functions such as HAL_GPIO_WritePin.

L04 exit ticket - the answers

GPIOA->MODER &= ~(3U << 10);
GPIOA->MODER |=  (1U << 10);

01 POINTER MEMBER — the MODER member of the register structure that the CMSIS pointer GPIOA points to.

02 MASK — 3U << 10 selects bits 11 and 10, PA5’s mode field.

03 RESULT — clear then set leaves 01: general-purpose output.

04 HARDWARE — read GPIOA->MODER in the SFR view (bits 11:10 = 01); ODR/LD2 confirm the output path.

Today: the exact same bits — written by a function with names instead of masks.

GPIO_InitTypeDef holds the pin settings

GPIO_InitTypeDef output = {0};

output.Pin   = GPIO_PIN_5;
output.Mode  = GPIO_MODE_OUTPUT_PP;
output.Pull  = GPIO_NOPULL;
output.Speed = GPIO_SPEED_FREQ_LOW;

GPIO_InitTypeDef is a structure type supplied by the STM32 HAL headers. output is our variable name, and the dot selects one setting inside it.

The {0} initializes every member to zero before individual settings are assigned.

Type definition: stm32f4xx_hal_gpio.h, lines 46–62 (in VS Code: Ctrl/Cmd + click GPIO_InitTypeDef) · Deep dive: UM1725 Rev 8, GPIO functions — p. 447.

Four pin settings in GPIO_InitTypeDef

01 Pin selects PA5 using the mask GPIO_PIN_5.

02 Mode requests push-pull output: the pin can actively drive both high and low.

03 Pull requests no internal pull resistor.

04 Speed requests the low output transition-speed setting.

HAL_GPIO_Init(GPIOA, &output);

&output passes the structure’s address so the function can read its members.

HAL settings map to register bits

HAL configuration Register effect for PA5
GPIO_PIN_5 select pin 5
GPIO_MODE_OUTPUT_PP MODER[11:10] = 01, OTYPER[5] = 0
GPIO_NOPULL PUPDR[11:10] = 00
GPIO_SPEED_FREQ_LOW OSPEEDR[11:10] = 00 
HAL_GPIO_Init(GPIOA, &output);

The HAL function converts the named settings into register operations.

Deep dive: RM0368 Rev 6, §8 GPIO — p. 146.

The generated init code

MX_GPIO_Init() sets up the pins you chose in CubeMX. Here it makes PA5 (LD2) an output that starts low. main() calls it once, before the while (1) loop.

static void MX_GPIO_Init(void)
{
    GPIO_InitTypeDef config = {0};
    __HAL_RCC_GPIOA_CLK_ENABLE();
    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET);
    config.Pin   = GPIO_PIN_5;
    config.Mode  = GPIO_MODE_OUTPUT_PP;
    config.Pull  = GPIO_NOPULL;
    config.Speed = GPIO_SPEED_FREQ_LOW;
    HAL_GPIO_Init(GPIOA, &config);
}

Read top to bottom: clock → safe starting level → settings → initialization. Here, generated static means this helper is used only inside this source file.

Driving an output with HAL_GPIO_WritePin

HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);

Three HAL GPIO functions at run time

Function Job Result
HAL_GPIO_WritePin(port, pin, state) force high or low no return value
HAL_GPIO_TogglePin(port, pin) reverse the output no return value
HAL_GPIO_ReadPin(port, pin) sample an input GPIO_PIN_SET or GPIO_PIN_RESET

Configuration happens once. These functions are used while the program is running.

Each function is a few lines of C: stm32f4xx_hal_gpio.c — read HAL_GPIO_WritePin and find the BSRR write.

ODR and IDR: the GPIO data registers

Register What it holds HAL function
ODR (output data) the value an output pin drives WritePin sets or clears it through BSRR. TogglePin reads it, then writes BSRR.
IDR (input data) the level on the pin now; read-only ReadPin reads it.

In the register view, ODR5 = 1 means LD2 is driven high, and IDR13 = 0 means B1 is pressed.

In stm32f4xx_hal_gpio.c, HAL_GPIO_ReadPin reads IDR and HAL_GPIO_TogglePin reads ODR.

A GPIO pin as an input

So far PA5 was an output: the program sets the pin voltage. On an input, a circuit outside the chip sets the voltage, and the program reads it.

A floating input reads random values

An input reads a clear value only if a circuit holds the pin high or low. With B1 open and no pull resistor, nothing drives PC13: noise moves its voltage, and each read can give a different value.

Pull-up and pull-down

While B1 is open, only the resistor sets the level of PC13.

PUPDR selects the internal pull resistor

Two-bit field Internal connection
00 no internal pull
01 internal pull-up
10 internal pull-down
11 reserved

PC13 starts at bit 13 × 2 = 26, so its two-bit field is bits 27:26.

Deep dive: RM0368 Rev 6, GPIOx_PUPDR — p. 159.

Choosing the pull setting

What the pin reads when nothing drives it Pull setting PUPDR HAL setting
set by the board (B1: R30 pulls it to 1) no internal pull 00 GPIO_NOPULL
1 pull-up 01 GPIO_PULLUP
0 pull-down 10 GPIO_PULLDOWN 
config.Pull = GPIO_NOPULL;

The Nucleo button already has an external pull-up, so it does not need an internal one.

Source: STM32F401xD/xE datasheet, DS10086 Rev 5, Table 54 — p. 92: internal pull-up and pull-down are 30–50 kΩ (typical 40 kΩ); each is a resistor in series with a switchable transistor.

Button B1 on PC13 is active-low

B1 USER ON PC13

  • R30 holds PC13 high while B1 is released.
  • Pressing B1 connects PC13 to ground.
  • Released → GPIO_PIN_SET
  • Pressed → GPIO_PIN_RESET

The button is active-low: pressed means logic 0.

Source: official MB1136 C04 schematic · UM1724 Rev 17, p. 24 · ST Nucleo BSP.

Configuring PC13 as an input

GPIO_InitTypeDef config = {0};

__HAL_RCC_GPIOC_CLK_ENABLE();

config.Pin  = GPIO_PIN_13;
config.Mode = GPIO_MODE_INPUT;
config.Pull = GPIO_NOPULL;

HAL_GPIO_Init(GPIOC, &config);

No output speed is required for a plain input.

Reading B1 with HAL_GPIO_ReadPin

GPIO_PinState button = HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13);

B1 is active-low: pressed reads GPIO_PIN_RESET (0).

Polling B1 to control LD2

while (1) {
    GPIO_PinState button = HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13);
    if (button == GPIO_PIN_RESET) {   // pressed
        HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);
    } else {
        HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET);
    }
}
