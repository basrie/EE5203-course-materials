B1 Press Counter

A press is a change, from released (1) to pressed (0). One reading shows only the state now, so the loop compares the reading from the last pass, previous, with the reading from this pass, current. Press B1, step through the loop and watch press_count.

Lab 4, Checkpoint C — one pass of while (1)

GPIO_PinState current = HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13); /* a press starts: released before, pressed now */if (previous == GPIO_PIN_SET && current == GPIO_PIN_RESET) {    press_count = press_count + 1;    HAL_Delay(20);        /* ignore contact bounce */}previous = current;
