A GPIO pin cannot dim an LED or time a signal

Since L04 a pin has been either 0 V or 3.3 V. Two jobs in this course need more than that:

Today the L07 timer takes over a pin: it drives the pin (PWM) and it timestamps the pin (input capture). You will choose PSC, ARR, CCR and turn timestamps into period and duty.

Retrieval: the timer time base from L07

L07 exit ticket: Prescaler = 1599, Period = 249, timer clock 16 MHz.

Nothing from L07 changes today. PSC, CNT, ARR and the update event stay; one register per channel is added: CCR.

PWM switches a pin fast with a chosen duty cycle

duty cycle D = tₕ ÷ T · average voltage = D × 3.3 V

T: the period, one full cycle. tₕ: the high time in each period. In-lecture demos: duty and average · PWM through an RC filter.

A compare register CCR turns the counter into PWM

PWM mode 1: the pin is HIGH while CNT < CCR1, and LOW from the match until the update event.

Deep dive: RM0368 Rev 6, §13.3.9 PWM mode — p. 336.

PWM frequency comes from ARR, duty from CCR

PWM frequency = timer clock ÷ ((PSC + 1) × (ARR + 1))
duty cycle = CCR ÷ (ARR + 1)

Keep PSC = 15 all term: 16 MHz ÷ 16 = 1 MHz, so one count is 1 µs. Then ARR + 1 is the period in µs and CCR is the high time in µs.

1 kHz at 35 %: PSC = 15, ARR = 999, CCR1 = 350.

CCR1 pin with ARR = 999 duty
0 never HIGH 0 %
350 HIGH for 350 of 1000 counts 35 %
999 HIGH for 999 of 1000 counts 99.9 %
1000 CNT < 1000 is always true 100 %

The +1 rule again: LD2 fully on needs CCR = ARR + 1, not CCR = ARR.

PWM output reaches PA5 through AF1

PA5 must be handed over from GPIO to TIM2. Two GPIO registers do it, both from L04.

PA5 is LD2. The LED you have blinked since L01 is wired to TIM2_CH1: dimming it needs no extra wiring.

Change the PWM duty by writing CCR

HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_1);            // once, after the init
__HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_1, 250);   // 25 %
__HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_1, 800);   // 80 %, from the next period

After Start the hardware makes the waveform by itself. A new duty is one register write, used from the next update event: no half-length pulse.

Breathing LEDEvery 10 ms the duty steps up or down by 5. 1 check the time 2 step the duty 3 write it to CCR1. Timeg_ms is the L07 tick from the TIM2 update interrupt. Four PWM channels share one timer frequency

TIM2 to TIM5 have four channels each: CCR1 to CCR4, one comparator each, one shared counter.

One timer gives one frequency and up to four duty cycles. A 1 kHz LED and a 50 Hz servo need two different timers.

A servo reads the PWM pulse width as an angle

PSC = 15 → 1 µs · ARR = 19999 → 20 ms, 50 Hz · CCR = pulse width in µs

Keep CCR inside 1000–2000: outside that range a hobby servo pushes against its end stop. It holds the angle as long as the pulses keep coming.

Practice: set a servo angle with CCR

A servo on TIM3 CH1 with PSC = 15 and ARR = 19999: 1000 µs is 0°, 2000 µs is 180°.

45° is a quarter of 180°: 1000 + 0.25 × 1000 = 1250. 2600 µs is outside the 1000–2000 contract: the servo strains against its end stop. No: the channels of one timer share ARR, and the LED needs 1 kHz while the servo needs 50 Hz.

Input capture: a pin edge copies CNT into CCR

The same channel, the other direction. An edge on the pin makes the hardware write CCR1.

Same CCR1, two directions: for PWM your code writes it, for input capture the hardware writes it.

Deep dive: RM0368 Rev 6, §13.3.5 Input capture mode — p. 333.

Input capture timestamps an incoming signal

PSC = 15, ARR = 65535: CNT runs freely, one count per µs. A capture is the time of an edge.

In-lecture demo: interactive capture animation. The HAL call that reads CCR1: UM1725 Rev 8, HAL_TIM_ReadCapturedValue — p. 1097.

Duty cycle needs two capture channels on one pin

CH1 (direct) captures rising edges on PB6. CH2 (indirect) captures falling edges on the same pin.

The hardware can also do this pair by itself, with a counter reset on every rising edge: RM0368 Rev 6, §13.3.6 PWM input mode — p. 334. It costs the whole timer.

Input filter and overcapture in input capture

01 FILTER: ICFilter 0–15: an edge counts only after N equal samples. It is the L06 debounce idea, done in hardware.

02 OVERCAPTURE: CC1OF in SR: a new edge overwrote CCR1 before your code read it. The code is too slow for the signal.

Common PWM and input capture mistakes

01 WRONG CLOCK: 84 MHz numbers on our 16 MHz timers: every frequency 5.25× off.

02 PIN STILL GPIO: PA5 still GPIO_Output, MODER = 01: WritePin works, PWM does not.

03 MISSING +1: CCR = ARR gives 99.9 %. Fully on needs CCR = ARR + 1.

04 SHARED ARR: the 1 kHz LED and the 50 Hz servo on one timer. They share ARR.

05 WRONG WIDTH: uint32_t p = now - last; reads 4294911296 after a wrap. Cast to (uint16_t).

06 NEVER STARTED: no HAL_TIM_IC_Start_IT(), or the TIM4 NVIC box unticked: the callback never runs.
