Input capture: the timer stamps each edge

TIM4 counts once per microsecond (PSC = 15, ARR = 65535). When PB6 rises, the hardware copies CNT into CCR1. When PB6 falls, it copies CNT into CCR2. Your callback only subtracts. Time runs in slow motion.

Keys: Space play / pause · → step · R reset. Changing the signal starts again from 0.

PB6 and the TIM4 counter, on one time axis

rising edge → CCR1 falling edge → CCR2 hollow: not read yet · filled: read by the callback · ✕ overwritten before it was read ▲ callback ran

TIM4 registers (what the SFR view shows)

TIM4->CNT0counts 1 per µs
TIM4->CCR10last rising edge
TIM4->CCR20last falling edge

TIM4->SR flags

CC1IF0 CC1OF0 CC2IF0 CC2OF0

CCxIF = 1: a new capture waits in CCRx. Reading CCRx clears it. CCxOF = 1: a new edge overwrote a capture that nobody had read. The HAL does not clear CCxOF; your code has to.
