Bitwise Lab

EE5203 Microprocessors · practise masks, shifts and register writes. Nothing you type is sent or recorded.

Register

Statement

Predict the result first. Ctrl+Enter also runs.

Board: LD2 on PA5

Patterns

  • x |= (1U << n);set bit n
  • x &= ~(1U << n);clear bit n
  • x ^= (1U << n);toggle bit n
  • x &= ~(3U << 2n);
    x |= (1U << 2n);    pin n mode field = 01 (output)
  • GPIOA->BSRR = (1U << n);PAn high
  • GPIOA->BSRR = (1U << (n + 16));PAn low

Names you can use: value, RCC->AHB1ENR, GPIOA->MODER, GPIOA->ODR, GPIOA->BSRR.

Registers follow the STM32F401 reference manual (RM0368): RCC_AHB1ENR, GPIOx_MODER, GPIOx_ODR, GPIOx_BSRR. The register view is a model for practice; values on your board can differ in bits this page does not use.
